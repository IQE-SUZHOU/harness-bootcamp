# Scope list

Instruction sources that apply to this repository, from lowest to highest precedence.

| Scope | Trigger | Source | Precedence |
| --- | --- | --- | --- |
| User global | Always | `~/.dsh/AGENTS.md` (if present) | Lowest |
| Shared agents | Always | `~/.agents/AGENTS.md` (if present) | Low |
| Project | cwd under repo root | `AGENTS.md` | Medium |
| Nested | Read/write reaches a deeper directory | `packages/**/AGENTS.md` | High |
| Local overlay | Same as nested | `*.local.md` | Highest |

## Repository boundary

- Allowed: read/write inside the repository root.
- D2/D3 exception: `demos/day2/interrupt-resume-demo.sh` and
  `demos/day3/maker-checker-demo.sh` write `dsh` session state under
  `$DSH_HOME/sessions/` (default `~/.dsh/sessions/`). No other external writes
  are allowed. For any other task outside the repository, the agent must reply
  `该任务超出本仓库范围` and stop.
- `CLAUDE.md` is a symlink to `AGENTS.md`, so instructions must be injected
  once, not twice.

## Artifact boundary

| Path | Tracked | Rule |
| --- | --- | --- |
| `d2-artifacts/` | No | Generated by the D2 demo; may contain machine-local paths |
| `demos/day2/evidence/` | Yes | Sanitized snapshot only: replace absolute paths with `<repo-root>` and the project key with `<project-root-slug>` |
| `d3-artifacts/` | No | Generated by the D3 demo; contains the working copy, raw NDJSON, and decompressed sessions |
| `demos/day3/evidence/` | Yes | Sanitized snapshot only: paths replaced, human token redacted as `<human-token>` |
| `$DSH_HOME/sessions/` | No | Runtime state; read-only evidence for the demo, never edited by hand |
