# src/.env — harness 网关配置（真实密钥只住 `.env`，不入库）

`harness.py` 的 `env()` 读配置：**环境变量优先，其次本目录 `.env`**，都没有返回
`None`（必填项由 `provider_chain()` 统一报错）。值原样读取——`MODEL` 里的空格是
模型名的一部分，不要加引号。

| 变量 | 必填 | 作用 |
|------|------|------|
| `BASE_URL` | 是 | 模型网关 OpenAI 兼容入口；主备 key 共用同一个网关 |
| `API_KEY` / `MODEL` | 是 | 主 key 及其模型（ZX 专用别名，主 key 名下只放行这一个模型） |
| `FALLBACK_API_KEY` / `FALLBACK_MODEL` | 成对可选 | 备用 key 及其模型；两个要么都配要么都不配，配了即启用兜底链 |
| `LLM_TIMEOUT` | 否 | 单次调用超时秒数，默认 200 |

## 主备语义（`call_llm`）

1. 每次调用先走主 key：超时/连接失败/5xx 按 `NET_RETRIES=3` 重试（退避 5s、10s）。
2. HTTP **401/403/429 重试无意义**（鉴权/配额问题），当次直接放弃这个 key 换下一个。
3. 换下去的 key 在**本进程内记死**（sticky）：后续步骤直接用备用 key，不再每个调用
   白等 3 轮超时；下次重跑命令时再从主 key 试起。
4. 所有 key 用尽 → 打印 `模型网关不可用...` 并退出 1，状态停在最后一个成功步，
   重跑同一条命令即可续跑。

只配 `API_KEY`/`MODEL` 不配 `FALLBACK_*` 时，行为退化为单 key——与旧版完全一致。

## 密钥纪律

- 本文件（`.env.md`）**禁止写入真实 key**；真实 key 只进 `.env`（已被 `.gitignore`
  忽略）。网关地址与 key 分发走线下。
- `make contract` 的 no-secret 门禁只扫仓库根顶层 `*.md`，扫不到这里——别指望它兜底。
